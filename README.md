# School-Connect

School-Connect is a school management platform connecting:

- Administrators
- Teachers
- Parents
- Students

## Main Modules

### Admin

- Students
- Teachers
- Staff
- Attendance
- Holidays
- Profiles
- Achievements
- Leave approvals
- Health information
- Exams
- Results
- Performance
- Notices
- Messages
- Calendar
- Activities

### Teacher

- My Classes
- Students
- Attendance
- Homework
- Notices
- Messages
- Subjects
- Parent communication
- Student performance
- Exams
- Results
- Activities
- Achievements
- Teacher remarks

### Parent

- Student profile
- Attendance
- Homework
- Messages
- Notices
- Results
- Monthly performance
- Academic performance
- Achievements
- Leave applications
- Calendar
- Teacher information
